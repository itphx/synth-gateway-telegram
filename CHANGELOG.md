# Changelog

## About

`synth-gateway-telegram` is the Telegram gateway (a **Gateway**-class add-on) for
the Synth agent platform. Its current version is **0.3.2** (see
[`package.json`](./package.json) and [`synth.pack`](./synth.pack)).

Full release notes are published on the **Releases** page, generated by CI for
every tag `vX.Y.Z`:

- GitVerse — <https://gitverse.ru/itphx/synth-gateway-telegram/releases>
- GitHub (mirror) — <https://github.com/itphx/synth-gateway-telegram/releases>

Previous tags include `v0.1.0`, `v0.2.0` and `v0.3.2` — see the Releases page for
the corresponding notes.

Gateways are **versioned independently of the Synth core**: their version numbers
are not tied to `@itphx/synth-*`. Compatibility with a core version is declared by
the `host` field in [`synth.pack`](./synth.pack).
